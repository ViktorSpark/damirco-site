Инструменты КАТАЛОГ ИНСТРУМЕНТОВ Абразивные инструменты : шлифовальные диски, круги, ленты. Аксессуары для химических анкеров : пистолеты для картриджей инжекционной массы, гильзы, смесители-насадки, щётки для чистки отверстий. Заклепочники ручные механические для вытяжных заклепок 2.4, 3.2, 4.0, 4.8 мм и резьбовых заклепок от М5 до М10. Клещи для стопорных колец, клещи зажимные, клещи переставные, пассатижи комбинированные, бокорезы усиленные, длинногубцы, гвоздодёры. Ключи шестигранные, ключи гаечные разводные, ключи-трещотки, биты для шуруповерта PH, SPAX, кровельные, антивандальные . Наборы профессиональных ручных инструментов, г-образных ключей, гаечных двусторонних рожковых ключей. Ножи складные с быстросменными трапециевидными лезвиями, ножницы многофункциональные из нержавеющей стали. Отвертки универсальные. Свёрла по металлу HSS с цилиндрическим хвостовиком. Свёрла по дереву перовые с шестигранным хвостовиком. Буры по бетону с хвостовиком SDS-plus, SDS-max. Фрезы для пазов сег
