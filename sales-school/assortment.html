Объёмы — по фактическому каталогу. Бренды перечислены по доле позиций.

01

Механические анкеры — 661 позиция

Крепление без химии: клиновые, распорные, цанговые, анкер-шурупы. Основа любого объекта. Лидеры: MKT, RAWLPLUG, A-KA, Graf, Fasty, HILTI.
Клиновые анкеры (Graf, MKT) — для бетона и кирпича с высокой статической нагрузкой. Распорные — для стен неутеплительных. Анкер-шуруп MUAF — быстрый монтаж без распора.
02

Деревянное домостроение — 452 позиции

Крепёж для деревянных конструкций: HIMTEX — монополист категории. Каркасное домостроение, крыша, обрешётка, балки, холодный/тёплый контур.
Это драйвер сезона: спрос на деревянный крепёж растёт к лету. Для ЛПР из стройки — категория №1 по объёму запросов.
03

Дюбели — 307 позиций

Стальные, нейлоновые, фасадные, по газобетону, по гипсу. Бренды: ЕКТ, Holdex, Rawplug, Fasty, Дюбели Райс-Токс, Daxmer.
Универсальный крепёж «на каждый день» — покупают все. Нейлоновый дюбель для внутренних работ, распорный для фасада, специальный для газобетона.
04

Саморезы — 212 позиций

По металлу, дереву, кровельные, фасадные, с буром, окрашенные под RAL. Бренды: RAWLPLUG, Fasty, KOELNER (+ саморезы под металлочерепицу).
Саморез под RAL — лёгкий апселл к анкерам и дюбелям: «Из одной отгрузки закроем и фасад, и кровлю».
05

Быстрый монтаж — 201 позиция

Гвозди по газобетону, монтаж без распора, быстрая фиксация. Ключевой продукт для ускорения монтажа на объекте.
Ценность для клиента: меньше времени на крепёж — меньше простоев бригады. Отличная история для «Предложения под потребность».
06

Заклёпки — 118 позиций

Вытяжные, по металлу и композитным панелям. Бренд-лидер: FIXOL.
Часто уходят вместе с анкерами на фасадные и кровельные работы. Лёгкая кросс-продажа.
07

Химические анкеры — 112 позиций

Инъекционная химия для высоконагруженного крепления: RAWLPLUG, HIMTEX, BIT, MKT, HILTI, Fasty.
Продаётся с принадлежностями (категория 08): картриджи, пистолеты, дозаторы. Наличие обоих — преимущество перед конкурентами.
08

Принадлежности для хим. анкеров — 56 позиций

Пистолеты, дозаторы, промывка, сетки, вкладыши. Закрывают потребность «купить сразу всё для хим. крепежа».
Продавайте хим. анкер вместе с принадлежностями — клиент не пойдёт искать их в другом месте.
09

Фасадные дюбели — 27 позиций

Крепление утеплителя и фасадных систем. Узкая, но маржинальная категория.
Формула: анкер под фасад + фасадный дюбель + саморез под RAL = весь фасадный объект из одной отгрузки.
10

Самосверлящие винты — 27 позиций

Крепёж с буром — сверлит сам, не требует предварительной подготовки. Для сэндвич-панелей и быстро собираемых конструкций.
Короткая сделка под ключ для «горячих» заявок на сборные объекты.

Премиум / топ качества

Graf, HILTI, MKT — для ответственных конструкций и проектных объектов. Цена выше, аргумент — надёжность.

Проверенный средний сегмент

RAWLPLUG, HIMTEX, FIXIN, Fasty — основная база продаж. Хорошо известны, широкий ассортимент.

Экономичные

Daxmer, Tech-krep, ЕКТ, FIXOL — для клиентов, чувствительных к цене. Аргумент при «дорого»: схожие характеристики дешевле.

Спор с клиентом о брендах — проигрыш. Стратегия: «есть премиум Graf, есть экономичный Daxmer — какой критерий для вас важнее: цена или испытания?»
