Описание

Держатель теплоизоляции (Дюбель тарельчатый) со стальным гвоздем с термоголовкой DTI-10 (универсальная распорная зона)10х90 Держатель теплоизоляции (дюбель для теплоизоляции, тарельчатый дюбель) используется для крепления термоизоляционных материалов во все типы стеновых материалов (бетон и полнотелый керамический кирпич, пустотелый кирпич, блоки с пустотами, керамзитобетон, газобетон).&amp;lt;br&amp;gt; Характеристики:&amp;lt;br&amp;gt; крепежная система состоит из распорного дюбеля диаметром 10 мм с удерживающим диском диаметром 60мм. Комплектуется гвоздем из оцинкованной стали с наплавленной термоизоляционной головкой.&amp;lt;br&amp;gt; Преимущества:&amp;lt;br&amp;gt; - использование наплавленной термоизоляционной головки позволяет уменьшить теплоотдачу между утепляемой поверхностью и окружающей средой, а также защищает стальной гвоздь от коррозии;&amp;lt;br&amp;gt; - перфорированная поверхность диска обеспечивает оптимальное нанесение штукатурки;&amp;lt;br&amp;gt; - продольные ребра на обратной стороне диска и на гильзе придают конструкции необходимую для монтажа жесткость.&amp;lt;br&amp;gt; Материал изготовления:&amp;lt;br&amp;gt; Держатель изготовлен из полипропилена, гвоздь - из оцинкованной стали, термоизоляционная головка - из нейлона.
