Тарельчатые дюбели F-IS20/50 (250шт/уп) (2000шт кор) без гвоздя Тарельчатые дюбели (грибы) для прямого монтажа Газовым пистолетом теплоизоляционных материалов к бетону и кирпичу.НЕ ИМЕЮТ предустановленного гвоздя. НЕ ИМЕЮТ Технического Свидетельства для использования на фасадах. Изготовлены из полиэтилена высокого давления. Рондель d50мм. Толщина прикрепляемого материала от 20 до 50мм. Используется для утепления внутри помещений. Для газовых монтажных пистолетов: FIXIN FGT95 с гвоздями F-CN32 , F-CN38 по прочному бетону и с гвоздями F-CNS32 , F-CNS38 по менее прочному бетону и кирпичу. ХАРАКТЕРИСТИКИ: Артикул: 2-1-6-1111
