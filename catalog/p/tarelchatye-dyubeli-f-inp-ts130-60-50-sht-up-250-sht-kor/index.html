Описание

Тарельчатые дюбели F-INP TS130/60 (50 шт/уп) (250 шт/кор) Тарельчатые дюбели (грибы) для прямого монтажа Пороховым пистолетом теплоизоляционных материалов к бетону и кирпичу. Имеют Техническое Свидетельство для использования на фасадах. Изготовлены из полиэтилена высокого давления, с предустановленным оцинкованным гвоздем. Рондель d60мм. Толщина прикрепляемого материала от 50 до 200мм. Для пороховых монтажных пистолетов: WALTE PT 950 IE, WALTE PT 274 IE, Hilti DX5 IE/DX460IE. Для повышения эффективности утепления можно использовать TS заглушки. ХАРАКТЕРИСТИКИ: Артикул: 2-1-6-2866
